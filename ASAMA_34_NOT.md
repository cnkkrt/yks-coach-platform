# Aşama 34 - Menü Mimarisi ve Haftalık Plan Merkezileştirme

## Yapılanlar

### Öğrenci paneli
- Menü sadeleştirildi:
  - Dashboard
  - Haftalık Plan
  - Denemelerim
  - Kaynaklarım
  - Performansım
  - Mesajlar
- Ödevler, hata odağı, video dersler ve çalışma kayıtları öğrenci menüsünde ayrı kalabalık başlık olarak gösterilmedi.
- Haftalık plan içine günlük ekstra çalışma kayıt formu eklendi.
- Haftalık plan içine gün gün ödev takip alanı eklendi.
- Öğrenci, koçun verdiği ödevi haftalık plan içinden tamamlandı olarak işaretleyebilir.
- Haftalık plan artık öğrencinin ana operasyon ekranı olacak şekilde güçlendirildi.

### Koç paneli
- Menü daha ticari/operasyonel dile çekildi:
  - Dashboard
  - Öğrenciler
  - Haftalık Planlama
  - Raporlar
  - Kaynak Kütüphanesi
  - Alarm Merkezi

### Admin paneli
- Menü kurum yönetimi mantığına göre sadeleştirildi:
  - Kurum Analitik
  - Kullanıcılar
  - Kaynak Havuzu
  - Sistem Ayarları

### Teknik doğrulama
- `npm install` başarılı.
- `npm run build` başarılı.
- Deploy yapılmadı. Deploy, tüm kritik özellikler tamamlandıktan sonra yapılacak.
