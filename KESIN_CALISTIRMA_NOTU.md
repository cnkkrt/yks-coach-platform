# Aşama 29 - Kesin Çalıştırma Notu

Bu paket, Aşama 28.1 üzerinde çalışan yapının panel ayrıştırması yapılmış temiz sürümüdür.

## Klasör adı

```text
yks-kocluk-platformu-asama-29-panel-ayristirma
```

## Çalıştırma

```powershell
npm install
npm run dev
```

## Kontrol

```powershell
npm run
```

Çıktıda şu scriptler görünmelidir:

- dev
- start
- build
- preview

## Not

Zip içinde `node_modules` yoktur. Bu klasör `npm install` ile kullanıcının bilgisayarında yeniden oluşmalıdır.
